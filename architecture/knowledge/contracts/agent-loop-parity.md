# Agent session loop parity

Claude, Codex and OMP are variants of one agent-session product contract. A provider is not complete merely because it starts and renders a transcript: launch, display, control, interaction, trust, failure and non-replay semantics are reviewed cell by cell. Legitimate provider asymmetry is explicit, scoped, sourced and time-bounded below.
