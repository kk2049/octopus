# 自主科研工作台 v2：集成交接

## 用户可见状态

- 一级“自主科研”入口：所有已登录用户默认可见，直接打开工作台。
- 已有项目：选中最近访问或最新可访问项目，显示人类可读项目名、最新会话和主导文档。
- 无项目：留在工作台壳层，显示创建或通过邀请加入的下一步。
- URL 邀请但未加入：同一壳层内显示项目名、席位和加入动作；成功后原地进入工作台。
- 空项目：展示接入 Agent/邀请成员的下一步。
- 归档项目：保留阅读与历史，隐藏或禁用改变状态的动作。
- pending/refused：阻止重复操作；拒绝文本有界且不丢失当前项目与填写内容。

## 数据需求

- 当前用户可访问项目的稳定 handle、人类标题、摘要、归档状态、最近活动和当前角色。
- 当前项目的 viewer-safe projection：最新会话、主导会话、主导文档、工作区分组、成员摘要和可用 controls。
- 全局首选/最近项目；没有偏好时使用最近活动项目。
- 可信外层提供当前项目的分享 URL、席位和成员管理能力；这些信息不进入不可信 action 参数。

## 用户意图

- 切换项目：导航到同一 App 的另一个共享实例，不产生项目业务事件。
- 折叠导航：纯本地显示偏好。
- 复制分享 URL：可信外层读取当前实例 URL，不产生 App 事件。
- 邀请、加入、成员管理：使用共享实例的可信 Host surface，不由 View 自行表达 identity/role。
- 阅读会话/文档：只切换当前 projection 中已有的稳定标识。
- 项目变更与 Agent 发布：继续使用声明的项目 actions，并遵守 projection controls。

## 集成约束

- 一级入口不得枚举实例卡片或把 hash 当标题；它只负责进入 App 工作台。
- App 内项目导航需要可信 Host 提供可访问实例目录或同源外层导航，不能让 View 枚举越权实例。
- 未加入状态与成员管理必须留在可信外层；视觉上可以属于同一侧栏，但不能下放 authority。
- URL 可以保留不透明 handle 作为路由实现，默认 UI 不展示它。
- 当前项目选择不得覆盖用户明确选择；失效项目应给出恢复路径，不静默跳到无关项目。

## C1 需要核对的契约差距

- 现有全局面板是否支持“默认所有用户可见、单卡直接 open”的声明方式。
- 可信 App Host 是否已有实例目录、加入和成员管理的嵌入式侧栏 surface。
- View 是否能请求外层打开项目导航/成员面板，或需要由外层扩展单窗口 chrome。
- 最近项目能否由可信 Host 推导；若没有，首版使用最近活动的可访问实例且不伪造持久偏好。
