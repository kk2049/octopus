# Fieldnote 科研项目工作台：集成交接

## 产品边界

这个界面管理的是“资助科研项目”授权单位，不是任意 workspace 的聚合首页。每个查看者只应收到其可见项目，以及项目内允许显示的成员、当前主导对象、会话、文档摘要和历史。

## 用户可见状态

| 状态 | 必需显示 | 可用动作 |
|---|---|---|
| 首次使用 | 项目身份、尚缺的主导对象、第一步 | Owner 绑定 agent；完成后再绑定文档 |
| 正常 | 当前 agent/会话、当前文档、项目摘要、角色允许的历史与成员 | 读会话/文档；Owner 可绑定与邀请 |
| 密集 | 分组项目、未读/健康摘要、长会话与大量历史 | 保持项目选择和滚动位置 |
| 提议处理中 | 原权威值、所提交候选、等待提示 | 禁止同一动作重复提交；允许关闭但不丢输入 |
| 提议被拒绝 | 有界原因、原权威值、保留的候选/说明 | 清除旧拒绝后重试或取消 |
| 已接受 | 新权威值和追加的历史记录 | 打开新主导对象；旧引用仍可追溯 |
| 结项/只读 | 结项时间、最后主导对象、历史内容 | 只读；不渲染绑定、邀请或成员变更动作 |
| 传输不可用 | 上次权威快照（如允许）、明确离线状态 | 不假装提交；恢复后由用户重试 |

## 查看者安全的数据需求

- 项目目录：项目稳定标识、显示名称、资助/组合标签、查看者角色、生命周期、允许显示的健康与未读摘要。
- 项目当前态：当前主导 agent 的安全显示信息及会话引用；当前主导文档的安全标题、类型、更新时间及可打开引用。
- 会话：仅项目策略允许的消息与思考摘要；文件意图必须是类型化、已授权的文件引用，不把消息内任意文本或 URL 激活。
- 文档摘要：可信来源的纯文本结构或已批准的类型化文档内容；不执行 HTML、脚本、data URL 或消息提供的路径。
- 历史：绑定类型、旧/新对象的安全标签、操作者安全标签、发生时间、原因摘要和结果。不可向 Viewer 泄露内部 agent 标识或成员身份。
- 成员：仅 Owner 获取完整成员/邀请管理字段；Member 获取协作所需的最小显示信息；Viewer 不获取邀请邮箱或管理元数据。
- 合法候选：可成为主导的 agent、会话和文档必须由当前项目范围计算，不能由浏览器拼接任意标识。

## 用户意图与抽象动作

- 选择项目并定位其最新主导会话和当前状态文档（导航，不改变权威状态）。
- 提议切换主导 agent：只发送项目内合法候选的槽位标识和有界说明。
- 提议切换主导文档：只发送项目内合法候选的槽位标识和有界说明。
- 查看 agent/文档主导历史（只读、分页）。
- 创建项目邀请：发送受邀主体输入、固定角色和可选到期设置；接受邀请是受邀人的独立动作。
- 改变或撤销成员角色：Owner 专属且需要显式确认；不能作用于最后一个 Owner。
- agent 项目工具：读取自身已绑定项目的安全状态；提议主导 agent/文档变化；追加受约束的状态事件。工具调用方不提供 principal、项目授权、批准状态或工作目录路径。

## 动作生命周期

1. 界面从当前权威状态取得合法候选。
2. 用户明确提交；保留输入并锁定同类重复提交。
3. 等待期间继续显示旧权威值，不提前更新项目入口。
4. 接受后只依赖新的权威状态刷新当前值与历史。
5. 拒绝时显示有界原因并保留输入；重试前先清理已消费的拒绝记录。
6. 结项、只读或连接不可用时，不提供会产生写入的操作。

## 授权与挂载约束

- 项目成员资格是访问根；目录、agent 会话和工具能力都只能作为项目授权的派生绑定。
- 软链接/挂载是可信执行细节。界面和 agent 请求都不能指定任意宿主路径，也不能通过软链接逃出批准的项目根。
- 重复挂载、循环链接、跨项目目标、消失目标和名称碰撞必须由可信侧拒绝且不产生部分绑定。
- 邀请、成员角色和项目生命周期不能由项目 agent 工具改变。
- 所有投影按查看者裁剪；仅在 DOM 中隐藏字段不是隐私控制。

## 集成评审问题

- 当前会话展示和文件意图能力是否已有可复用、查看者安全的共享主体，可在不复制业务状态机的前提下嵌入？
- 当前数据契约是否能表达项目目录、主导 agent/文档及两类历史；不能表达的字段应补权威投影，不能在前端推断。
- 哪些绑定动作可由 Owner 直接执行，哪些由 agent 发起后需要策略批准？两者应复用同一权威动作而非维护平行状态。
- 文件打开是否已有类型化引用和授权检查；若只有自由文本路径，初版必须降级成不可点击文本。
- 成员邀请若尚无受信任身份解析和接受流程，初版应明确延后邀请写操作，而不能做看似成功的本地列表。

## C1/C2 验收重点

- 逐项建立“原型状态 → 权威字段”“用户意图 → 精确动作参数”“角色 → 字段/控制”映射。
- 集成版本与本原型并排比较，保留项目导航、双主导入口、会话/现状并列层级以及拒绝恢复行为。
- 覆盖 Owner/Member/Viewer DOM、精确动作参数、重复提交、拒绝重试、结项只读、恶意字符串不激活、窄屏布局和打包闭包。
